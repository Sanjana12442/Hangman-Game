# Hangman-Game
A simple Hangman game made using Python where players try to guess a hidden word one letter at a time. This project helped me practice basic Python concepts like loops, conditions, strings, lists, and random selection.

About the Project

I created this Hangman game as a beginner Python project to practice the basics of programming. It's a simple word-guessing game where the computer picks a random word, and the player has to guess it one letter at a time.

The goal is to guess the word before making 6 incorrect guesses.

Features
Picks a random word from a list of 5 words
Lets the player guess one letter at a time
Shows the letters guessed correctly
Keeps track of incorrect guesses
Allows a maximum of 6 incorrect guesses
Checks for repeated or invalid guesses
Displays a message when the player wins or loses

Technologies Used
Python 3
Random module
While loop
If-else statements
Strings and lists

How to Run the Game
Make sure Python 3 is installed on your computer.
Download or clone this repository.
Open the project folder in your terminal.
Run the following command:
   python hangman.py

How to Play
Run the program.
The computer will select a secret word.
Enter one letter whenever you're asked to guess.
If your letter is correct, it will appear in the word.
If your guess is wrong, your incorrect guess count will increase.
Guess the full word before reaching 6 incorrect guesses to win!
