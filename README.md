# Hangman-Game
A simple Hangman game made using Python where players try to guess a hidden word one letter at a time. This project helped me practice basic Python concepts like loops, conditions, strings, lists, and random selection.

# About the Project

I created this Hangman game as a beginner Python project to improve my programming skills. The computer randomly picks a word, and the player has to guess it by entering one letter at a time.

The goal is to guess the complete word before making 6 incorrect guesses.

# Features
Randomly selects a word from a list of 5 words.
Allows the player to guess one letter at a time.
Displays correctly guessed letters.
Keeps track of incorrect guesses.
Allows up to 6 incorrect guesses.
Checks for repeated and invalid guesses.
Displays a message when the player wins or loses.

# Technologies Used
Python 3
Random module
While loops
If-else statements
Strings and lists

# How to Run the Game
Make sure Python 3 is installed on your computer.
Clone or download this repository.
Open the project folder in your terminal.
Run the following command:
   python hangman.py

# How to Play
Run the program.
The computer will randomly select a secret word.
Enter one letter when prompted.
If your guess is correct, the letter will appear in the word.
If your guess is incorrect, your mistake count will increase.
Guess the complete word before reaching 6 incorrect guesses to win!
